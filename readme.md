# منظومة تحليل نتائج شهادة البكالوريا ومطابقة الإعادة (BAC Analysis Tools)
**Official BAC Results Splitter, Repetition Matcher & Statistical Analysis Suite**

منظومة برمجية متقدمة مطورة بلغة **VBA for Excel (Office 365 / Excel 2021+)**، ومصممة خصيصاً لإدارات المؤسسات التعليمية الثانوية في الجزائر لمعالجة ملفات نتائج شهادة البكالوريا الأصلية الخام، استخراج وتحليل كل شعبة على حدة، مطابقة حالة الإعادة بدقة عبر ملفات الرقمنة (`Source03`)، وإنتاج تقارير إحصائية وحوصلة عامة متكاملة.

---

## المزايا المعمارية للبرنامج

1. **الاستخراج الديناميكي الذكي للشعب (`modBacEtab`):**
   * يقرأ الملف الخام للنتائج (`BAC????ResultatsOriginal.xlsx`)، ويطلب إدخال رمز المؤسسة عبر نموذج ديناميكي أنيق (`frmEtabCode`) لا يتطلب أي ملفات ثنائية `.frx`.
   * يوزع التلاميذ تلقائياً على الشعب التسع الرسمية (`Philo`, `LaEtr`, `Math`, `SE`, `GeEc`, `TGM`, `TGE`, `TGC`, `TGP`) مع تخصيص أعمدة المواد ومسمياتها بحسب المعاملات الوزارية لكل شعبة.

2. **مطابقة دقيقة لحالة الإعادة (`modStudentRepetitionStatus`):**
   * يجمع ملفات المجلد المصدر `\Source03\` في الذاكرة، ويطابق التلاميذ بين قوائم البكالوريا وقوائم الرقمنة بالاسم المطبع (`NormalizeArabicName`) وتاريخ الميلاد بدقة تامة.
   * يكتب حالة الإعادة (`نعم` / `لا`) في العمود `E` مع حماية الملف عبر نسخة احتياطية ذكية (`Backup_RepeatStatus_...`) لا تُحذف إلا بعد التحقق الفعلي من نجاح الحفظ.

3. **التحليل الإحصائي المتقدم والتجميد الذكي (`modBacAnalysis`):**
   * ينشئ ورقة الإحصائيات العامة (`Gen`) ويولد تحت كل شعبة شريط التعداد، وثلاثة جداول تفصيلية (متوسطات المواد حسب الجنس، المؤشرات الإحصائية المتقدمة بما فيها التباين والانحراف المعياري `STDEVP`، وتوزيع الفئات النقطية).
   * يقوم بتجميد المعادلات النهائية كقيم ثابتة (`FreezeAnalysisFormulas`) لحماية التقارير وضمان سرعة فتح المصنف الناتج.

4. **لوحة تحكم حديثة ومتطورة (`modBuildBacPanel`):**
   * واجهة تفاعلية ذات تصميم عصري تضم زراً رئيسياً موحداً (`RunBacAll`) لتنفيذ دورة العمل الكاملة بنقرة واحدة، بالإضافة إلى أزرار مراحل مستقلة مع مؤشرات حالة بصرية (`Chips`) وشريط معلومات حي.

## هيكل المجلدات والمخرجات

```text
📁 جذر المشروع (بجانب مصنف الأداة الرئيسي)
 ├── 📂 Source03\                  # مجلد رقمنة الفصل الثالث (يُقرأ لمطابقة الإعادة)
 ├── 📄 BAC2026ResultatsOriginal.xlsx # ملف نتائج البكالوريا الخام (المصدر)
 ├── 📄 <اسم المؤسسة>_BAC2026.xlsx  # مصنف النتائج والشعب المستخرجة والمحللة
 └── 📄 RepeatStatus_Report_...xlsx # التقرير التفصيلي لحالة الإعادة وتتبع المطابقة
```

## قائمة الوحدات البرمجية المكونة للبرنامج (5 Modules + 1 Form)

| رقم | اسم المكون (`VB_Name` / شكل) | الدور الوظيفي |
| :-: | :--- | :--- |
| 1 | `modBuildBacPanel` | بناء وإدارة لوحة التحكم التفاعلية (`ControlPanel`) ومتابعة حالة المراحل |
| 2 | `modBacEtab` | استخراج وتوزيع نتائج البكالوريا على أوراق الشعب التسع وترتيب التلاميذ |
| 3 | `frmEtabCode` | نموذج إدخال رمز المؤسسة ديناميكياً (بدون ملفات `.frx` خارجية) |
| 4 | `modStudentRepetitionStatus` | مطابقة الإعادة من مجلد `Source03`، الكتابة في العمود `E`، وإنشاء تقرير المطابقة |
| 5 | `modBacAnalysis` | بناء الجداول الإحصائية التفصيلية، ورقة الحوصلة العامة `Gen`، وتجميد الصيغ |

## متطلبات التشغيل

* **نظام التشغيل:** Windows 10 أو Windows 11.
* **إصدار أوفيس:** Microsoft Excel 365 أو Excel 2021 فما فوق.
* **الخطوط:** يعتمد افتراضياً خط الحواسب الإدارية `Hacen Saudi Arabia XL` للعناوين مع خطوط بديلة مدعومة.
